# GenAI Learning Journey 🚀

A structured repository documenting my hands-on learning journey in Generative AI, Retrieval-Augmented Generation (RAG), Vector Databases, and AI Engineering.

This repository focuses on understanding core GenAI concepts through practical implementation using Python, LangChain, ChromaDB, Hugging Face Embeddings, and PDF-based RAG pipelines.

---

# 📚 Topics Covered

- LangChain Basics
- ChromaDB Fundamentals
- CRUD Operations in Vector Databases
- Embeddings & Semantic Search
- Similarity Search
- Persistent Vector Storage
- PDF Loading using LangChain
- Chunking Strategies
- Retriever Workflow
- Basic RAG Pipeline
